# Telsa.io

A responsive starter website for an independent space, AI, electric-mobility and technology fan publication.

## Files

- `index.html` — page structure and content
- `style.css` — layout, colors, responsive styles and visual effects
- `script.js` — mobile navigation, community modal, tab switcher and demo form messages
- `readme.md` — setup notes

## Preview the site

1. Download all four files into the same folder.
2. Make sure the names are exactly `index.html`, `style.css`, `script.js`, and `readme.md`.
3. Open `index.html` in a browser, or upload the four files to your static website host.
4. If you edit the files in a website editor, save each file in the same project folder.

The site uses Google Fonts over the internet; system fonts will be used if they cannot load.

## Important before publishing

- This is an independent fan-made project, not an official Elon Musk, SpaceX, Tesla, xAI, or other company website. Keep that disclosure visible.
- The article cards are starter topics, not current news. Add reliable sources, publication dates, and accurate reporting before describing anything as breaking news.
- The newsletter form and account modal are front-end demonstrations only. They do not save email addresses, create accounts, or authenticate users.
- To enable real accounts, use a reputable authentication provider or secure backend. Never store passwords in browser JavaScript or local storage.
- To collect newsletter subscriptions, connect a newsletter service and publish an appropriate privacy notice.
- Replace the sample content and add only images and logos you have permission to use.

## Customization

- Change the page title and copy in `index.html`.
- Adjust the color variables near the top of `style.css`.
- Update interactions in `script.js`.
